# 真机验收清单

> 对象：`MicSwitcher.App\bin\Debug\net8.0-windows\MicSwitcher.App.exe`（22:00 之后的构建）
> 顺序建议 0 → 1 → 2 → 3 → 4。任一项失败就停下，把 `tray-diag.log` 整份留着，不要重启覆盖。

---

## 0. 启动

- [ ] 双击 exe，托盘出现**绿色麦克风图标**（不是空白方块）
- [ ] 鼠标悬停显示「MicSwitcher - 麦克风切换」
- [ ] 右键能弹出菜单，能看到「切换麦克风」「模式」这些项

失败时看：`tray-diag.log` 是否停在 `=== BuildTrayIcon 开始 ===` 之后就没内容。

---

## 1. 退出流程（昨天卡死的那条，最要紧）

- [ ] 托盘右键 →「模式」→「自动 · 按声音大小」
- [ ] 等 10 秒，确认 `tray-diag.log` 出现「电平跟踪」行（证明采集通道在跑）
- [ ] 托盘右键 →「退出」
- [ ] **菜单立刻消失**
- [ ] 任务管理器里没有 `MicSwitcher.App.exe`
- [ ] 日志末尾依次出现三行：`退出：开始` / `退出：服务已释放` / `退出：调用 Shutdown`

如果日志只到「退出：开始」就断了，说明还有别处阻塞——把整份日志留着，那是定位依据。

---

## 2. 自动切换

- [ ] 模式切到「自动 · 按声音大小」
- [ ] 对着其中一个麦克风连续说话 3–5 秒
- [ ] 默认麦克风应在 1 秒左右切过去（Windows 声音设置里看，或看托盘菜单第一行）
- [ ] 日志「电平跟踪」行的 `判定=` 应从 `NewCandidate` → `DebounceWaiting` → `DebouncePassed`

失败时看：
- 所有设备电平都是 `0.0000` → 采集通道没打开
- 有电平但一直不切 → 看 `判定=` 是 `Silent` 还是 `SameAsCurrent`

---

## 3. 拔插边界（锁定模式）

- [ ] 托盘右键 →「模式」→「锁定当前麦」
- [ ] 拔掉（或设备管理器里禁用）当前锁定的麦克风
- [ ] 预期：弹一次提示「锁定的麦克风「xxx」已不可用，已自动解除锁定」
- [ ] 预期：模式回到「手动」，**不再每秒弹窗**

旧版的表现是每秒一个错误弹窗、永远停不下来。这里对比很明显。

---

## 4. 设置滑杆（今天刚改的写盘节流）

- [ ] 打开「设置」→ 左侧「自动模式」
- [ ] 快速来回拖动「静音阈值」滑杆
- [ ] 预期：数值实时跟手，不卡顿
- [ ] 松手后等 1 秒，关闭设置窗口
- [ ] 重新打开设置，阈值停在你最后拖到的位置
- [ ] 检查 exe 同目录的 `settings.json`：修改时间是刚才，内容完整（用记事本打开能看到完整 JSON）

`SilenceThreshold` 是 0.001~0.5 的小数，拖到 2% 就是 `0.02`。拖到 0.4% 就是 `0.004`。

---

## 全过后

可以进发版：版本号升 1.0.1、打 tag，release workflow 会自动打出单文件包。

## 任一项失败

把这三样留着，不要重开覆盖：

1. `tray-diag.log` 整份
2. 出问题时的操作顺序（点了什么、等了多久）
3. 任务管理器里进程是否还在
